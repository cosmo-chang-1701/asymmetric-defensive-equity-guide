# 附錄 B：系統全流程量化參數與敏感度速查表

> **用途**: 實盤配置參數參考、回測參數掃描空間界定、敏感度壓力測試基準

---

## 系統核心參數速查表

| 參數模組 | 參數變數名稱 | 基準推薦值 | 敏感度安全區間 | 觸發意義與業務規則 |
| :--- | :--- | :---: | :---: | :--- |
| **PMPT 目標** | 最小可接受報酬率 ($MAR$) | $3.0\%$ (年化) | $0.0\% \sim 5.0\%$ | 索提諾比率評估門檻（對標 3 個月國債或通膨） |
| **會計篩選** | Sloan 應計比率上限 | $\le 0.10$ | $\le 0.12$ | 高於此值判定盈餘操縱與虛增利潤 |
| **信用防線** | Altman $Z\text{-Score}$ 門檻 | $> 2.99$ | $\ge 1.81$ | 低於 1.81 視為破產危險，一票否決 |
| **體質評分** | Piotroski $F\text{-Score}$ (常態) | $\ge 7$ | $7 \sim 9$ | 常態多頭標的體質入場門檻 |
| | Piotroski $F\text{-Score}$ (恐慌) | $\ge 8$ | $8 \sim 9$ | 左側抄底標的極致資產負債表韌性門檻 |
| **護城河回報**| 3 年平均 $\text{ROIC}$ | $\ge 15.0\%$ | $\ge 12.0\%$ | 資本配置優越性與實質價值創造 |
| | 自由現金流收益率 ($\text{FCF Yield}$) | $\ge 4.0\%$ | $\ge 2.0\%$ | 現金流安全墊（高成長科技股可放寬至 2%） |
| **宏觀體制** | SPY vs 200 SMA | 現價 > 均線 | 均線上揚 | 多頭體制基本條件 |
| | VIX 恐慌指標分區 | $< 20$ / $> 30$ | $20 \sim 30$ 為過渡 | 決定動能突破（$<20$）或反向價值（$>30$） |
| **動能進場** | 突破高點時間窗口 | 52 週 (252 日) | 20 週 $\sim$ 52 週 | 突破歷史結構阻力位 |
| | 成交量放大倍數 | $\ge 1.5 \times \text{VolMA}_{50}$ | $\ge 1.3 \times$ | 量增價揚確認機構實質買盤介入 |
| **風控停損** | ATR 吊燈停損倍數 ($K$) | $2.5 \times \text{ATR}_{14}$ | $2.0 \sim 3.0$ | 給予個股日常呼吸空間，避免雜訊洗盤 |
| | 最大初始停損百分比上限 | $8.0\%$ | $6.0\% \sim 10.0\%$ | 跌幅硬性天花板，防止低波時 ATR 距離過大 |
| **倉位風險** | 單筆實質風險 ($R\text{-Risk}$) | $1.25\%$ NAV | $1.0\% \sim 1.5\%$ | 單筆交易最大虧損額（即使看錯也不損核心元氣） |
| | 單檔股票部位價值上限 | $20.0\%$ NAV | $15.0\% \sim 25.0\%$ | 單一個股集中度上限，防止極端黑天鵝爆倉 |
| **移動停利** | 趨勢保護線 | 10 週 (50 日 SMA) | 跌破 2% 離場 | 獲利奔馳之戰略離場點，放任贏家奔馳 |
